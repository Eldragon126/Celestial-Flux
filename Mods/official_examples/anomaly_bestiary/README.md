# Anomaly Bestiary

Official example mod for enemy designers.

This pack demonstrates:
- `enemies` metadata for five readable enemy concepts.
- `enemy_packs` for grouping enemies.
- `wave_tables` for opt-in spawning.
- A creator option for safe spawn-weight tuning.

Copy this folder when making an enemy pack. Add scenes only when a trusted loader supports them, and keep every enemy readable: telegraph attacks, export health/speed/cooldowns, and avoid frame-heavy scans.
