# Collapsing Microverse Mode

Official example mod for custom mode authors.

This pack demonstrates:
- `gamemodes` and `campaigns` entries.
- Mode-specific celestial bodies and arena events.
- Challenge-card and wave-table requests.
- Multiplayer-safe scene flow through deterministic metadata.

Copy this folder when making a mode. Keep scene paths portable, use deterministic seed data for gameplay, and mark local presentation as `local_visual`.
