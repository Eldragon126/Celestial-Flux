# Relic Singularity Forge

Official example mod for upgrade and relic authors.

This pack demonstrates:
- `upgrades` metadata for eight relic concepts.
- Hookable `law_weaves` for event-driven passive behavior.
- HUD badges and score tags as safe side effects.
- Creator option metadata for future offer tuning.

Copy this folder when making relics. Keep passive effects bounded, give every dangerous payoff a telegraph, and make multiplayer-affecting fields deterministic.
