# Vector Anomaly Sellability Execution Plan

## The sentence

**Weaponize gravity in a physics roguelike where every impossible escape can be understood, repeated by seed, and shared.**

The store page, demo, trailer, creator site, and first five waves should all prove that sentence instead of listing systems.

## Conversion path

1. **Three-second proof:** player, gravity mass, threat, orange/cyan future path, impossible tangent exit.
2. **Ten-second proof:** one clean slingshot converts danger into a kill or recovery.
3. **One-minute proof:** basic movement, shooting, first gravity interaction, first behavior-changing reward.
4. **Demo proof:** waves 1-5 transition from tutorial-clean vectors to the first boss law without a performance collapse.
5. **Community proof:** seed codes and Clip Lab make the moment repeatable; the Creator Lab makes the game extensible.

## Implemented in this pass

- The first four wave rosters now teach one readable threat role at a time.
- Procedural field hazards arrive later, keeping the opening legible and lowering wave-4 crash pressure.
- Reduced Flash now preserves bullets and persistent gravity geometry, making accessibility footage sell the same fantasy.
- The public website now links a dedicated Creator Lab with a live manifest forge, starter download, JSON schema, searchable content surfaces, and shipping checklist.
- The in-game Mods screen can export a creator diagnostics report containing failures, dependencies, capabilities, install paths, and the multiplayer signature.

## Assets that unlock the next conversion step

- Replace placeholder site/trailer simulations with three real 3-6 second captures: apex recovery, gravity-assisted enemy kill, boss law mutation.
- Capture the same late-game scene in normal and Reduced Flash modes to prove readable spectacle.
- Put the strongest clip above all feature copy on Steam.
- Use one screenshot per promise: movement, gravity weaponization, boss rule, build identity, modding, and readable collapse.
- Publish one complete sample mod from install to in-game result; creator credibility needs proof, not only API breadth.

## Success measurements

- A cold viewer can describe the gravity hook after one clip.
- A new player reaches the first slingshot payoff inside 60 seconds.
- At least one shareable recovery occurs in a 10-minute demo run.
- Reduced Flash captures remain visually legible.
- A creator can generate, install, validate, toggle, and debug a starter pack without reading source code.
