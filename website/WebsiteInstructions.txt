# VECTOR ANOMALY - Website Consistency Brief

This website must reflect the current game, not an older prototype plan.

## Current Public Surfaces

- Primary public follow link: Discord, currently `https://discord.gg/HstMJMkCtb`.
- Current Windows playtest build: `https://github.com/Eldragon126/VECTOR-ANOMALY-WINDOWS-BUILD`.
- Current contact email from the repo README: `eldensimmons1@gmail.com`.
- Steam wishlist copy should only be shown when a real Steam app URL is configured in `site.config.js`.

## Core Positioning

Vector Anomaly is a physics-driven arena survival roguelike where the player survives by reading gravity, preserving momentum, slingshotting around mass, and turning dangerous physics into recovery routes.

The site should sell:

- movement as the primary survival skill
- readable trajectory and gravity pressure
- boss encounters as physics-rule mutations
- deterministic seed/run sharing
- watchable impossibility that remains fair in retrospect

Avoid framing the game as a generic twin-stick shooter, loot fantasy, bullet spam game, or pure power fantasy. The game has weapons and projectiles, so do not claim that the player literally does not shoot. Say that movement is the primary survival skill and that weapons support field control.

## No Web Slingshot Sandbox

Do not ship a runnable web slingshot sandbox. Represent slingshot mastery as static trajectory/readout proof and route deeper mechanics to the wiki. The real interaction belongs in the Godot game.

The trajectory section should show:

- entry vector
- gravity exposure
- tangent exit
- slingshot grade language
- a link to the wiki slingshot section

## Actual Run Progression

Use the current `RunProgress` and `WaveDirector` structure:

- Boss milestones are waves 5, 10, 15, 20, 25, 30, 35, and 40.
- Wave 5: Gravity Warden.
- Wave 10: The Accretion Core.
- Wave 15: Null Vector Seraph.
- Wave 20: Magnetar Twins.
- Wave 25: Tidal Rift Weaver.
- Wave 30: The Polymorph.
- Wave 35: Centrifuge Marshal.
- Wave 40: The Extradimensional Breacher.
- Defeating the wave-40 capstone enters Rupture.
- Rupture lasts 75 seconds.
- Music Finale spawns The Resonance Singularity.
- Defeating The Resonance Singularity transitions to credits.

Older copy that says the authored run ends at wave 35 is stale.

## Seed And Challenge Code Formats

Use the actual formats:

- Pause/run seed code: `mode:seed:wave`, for example `standard:7135:35`.
- Boss Rush mode id: `boss_rush`.
- Challenge/score code: `mode:seed:wave:score_checksum`, where the suffix is the numeric score, an underscore, then the checksum. Example: `standard:7135:35:12840_9F3AC12B0E`.

Avoid old hex-plus-wave-label marketing placeholders; they are not the current code format.

## Wiki Scope

The separate wiki site should stay factual and mechanics-first. It should cover:

- overview and positioning
- movement and trajectory prediction
- slingshot mastery
- resonance fields
- arena laws and chaos tiers
- run progression
- bosses and hidden bosses
- enemies
- powerups, law fusions, and physics drops
- seeds, scores, and challenge codes
- LAN co-op and future Steam transport
- safe modding manifests and hookable content
- accessibility and death readouts
- production architecture boundaries

## Production Architecture Claims

Only claim systems that exist in the docs/code:

- `RuntimeRegistry` cached discovery
- `OrbitalVFXDirector` pooled VFX
- `ParticleFocusCuller`
- `PerformanceBudgetDirector`
- `RunScoreTracker`
- `ModContentRegistry` and `ModHookDirector`
- `NetworkSession` LAN session layer
- `CoopComboDirector`
- `Production Simulation Runner`
- accessibility settings through `Settings`

## Visual Rules

Use the game's actual visual identity:

- stark black foundation
- crisp vector geometry
- cyan for gravity/readability
- amber for warning/trajectory
- red for critical/Rupture/boss pressure

Do not use generic space fantasy, muddy nebula fog, decorative bokeh, or abstract neon visuals that are disconnected from gameplay state.

Every marketing visual should answer at least one gameplay question:

- Where is the player?
- What force is acting?
- What danger is present?
- What recovery route exists?
- Why is this not a normal shooter?
